# TimeSpice — Filtres syllabus · distribution Firefox

Ce dépôt héberge **uniquement** le manifeste de mise à jour (`updates.json`) et les
paquets signés (`.xpi`) de l'extension Firefox, pour la distribution auto-hébergée
(self-distribution AMO). Le code source est dans un dépôt privé.

- `updates.json` : manifeste de mise à jour Firefox (référencé par `update_url`).
- Les `.xpi` signés sont publiés dans les *Releases*.
